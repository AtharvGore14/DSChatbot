# Multi-Agent Financial Data Chatbot using Advanced Data Structures

Phase 1 starter project with Flask templates and premium dark UI.

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Compile C++ engine

```bash
g++ -std=c++17 -O2 -o cpp_backend/ds_engine.exe cpp_backend/data_structures.cpp
```

## Run Flask app

```bash
flask --app app run --debug
```
